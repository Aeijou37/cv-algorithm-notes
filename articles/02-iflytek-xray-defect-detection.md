# 工业X射线无损检测：从两阶段评片到实例分割的全流程闭环

> 作者：李国杰 | 岗位：科大讯飞工业AI业务部 助理研究算法工程师（2026.5 - 2026.7）
> 系列：CV 算法工程笔记 · 第 02 篇
> 本文脱敏撰写，不涉及讯飞未公开数据与客户工艺细节。

## TL;DR

- **任务**：工业X射线无损检测（NDT）自动化评片，约500张超大图（>2000×2000）、10类缺陷、缺陷弱小低对比，需实现从底片输入到工件整体定性的全流程自动化。
- **基线**：Mask R-CNN 缩放版 mAP 仅 2.4%，裁剪版 6.8%，B类弱小缺陷召回仅 0.238——接近完全失败。
- **做法**：两阶段系统设计——阶段一：AHTF 自适应高重叠切片 + 类别合并（10类→3类）+ SDE/DAF 模型增强；阶段二：构建"缺陷分布→工件等级"定性规则。早期尝试 RF-DETR，后期转向 YOLO26-Seg（轻量、工程化好、便于快速消融）。
- **结果**：B类 Mask Recall 从 0.238 提升至 0.288（+21%），B类 Mask mAP50 从 0.216 提升至 0.239（+10.6%），all Mask mAP50 从 0.386 提升至 0.400。Boundary Loss（E4/E5）未超过 E3，当前形式不建议继续。
- **方法学沉淀**：大图小目标任务上**数据策略 > 模型增强 > 损失函数**——AHTF 切片策略贡献最大，SDE/DAF 模块次之，Boundary Loss 等简单 loss 改动在低对比度边界上收益不稳定。
- **部署闭环**：E3 模型 FP16 推理可部署至产线 GPU；大图回贴融合 + Qt 软件已完成原型，支持人工复核与结构化结果导出；阶段二大模型评片接口待联调。

## 一、问题定义：为什么"自动评片"不是简单的目标检测

### 1.1 任务背景

工业X射线无损检测（NDT）是铸件/焊缝等工件质量把控的关键环节。传统流程：X射线穿透工件 → 生成底片（灰度图）→ **人工评片师**逐张查看 → 标注缺陷位置和类型 → 根据缺陷分布判定工件等级。

自动化评片的目标：**输入底片 → 自动检出缺陷 → 自动判定工件等级**，全流程无需人工介入。最终交付一套集成增强算法、检测分割算法、以及大模型评片算法的评片系统软件。

### 1.2 为什么这不是普通的检测任务

| 难点 | 具体表现 | 为什么难 |
|---|---|---|
| 超大图 | 底片分辨率 >2000×2000 | 检测模型吃不下整图，必须切图，但切图可能切断缺陷 |
| 小样本 | 仅 ~500张 标注图 | 10类缺陷 + 每类样本少，部分罕见缺陷可能只有几十张 |
| 10类缺陷 | A气孔/B砂眼夹渣/Ca-Cd四类收缩/D裂纹/E热断裂/F镶件/G斑点 | 类别多且分布不均，收缩四子类形态相近 |
| 缺陷弱小低对比 | B类等缺陷与背景灰度差极小，边缘模糊 | CNN 浅层特征难以捕捉有效信号，漏检率高 |
| 整体定性 | 检出缺陷只是第一步，还要判定工件等级（1-5级）+ 主导缺陷类型 | 检测模型不管"等级"，需要额外规则引擎 |
| 标注困难 | 气孔与夹渣灰度相近难区分；混合缺陷难定性；等级2/3边界模糊 | 标注本身就存在主观性，模型上限受标注质量制约 |

### 1.3 两阶段式系统设计

```
阶段一：缺陷级检测与实例分割
  底片输入 → 图像增强 → AHTF切片 → YOLO26-Seg检测分割 → 每个缺陷的位置+类别+mask+面积

阶段二：工件级定性
  全部缺陷汇总 → 定性规则引擎 → 工件整体定性类别（气孔主导型/裂纹主导型/复合缺陷型等）+ 严重等级（1-5级）
```

两阶段解耦的理由：检测是"图上有什么"（计算机视觉问题），定性是"这个工件能不能用"（工程判断问题）。把它们分开，可以独立优化和验证，也方便业务方单独确认每个环节。

> **教训 #1**：这个任务的本质不是"把检测做到多高"，而是"把从检测到定性的全链路打通"。检测 mAP 再高，如果定性规则不对，系统对业务就是无用的。

## 二、基线：从 Mask R-CNN 到 YOLO-Seg 的路线调整

### 2.1 Mask R-CNN 可行性验证

早期选择 Mask R-CNN 的原因是原始标注为 JSON polygon，天然适配 COCO mask 格式。

**缩放版 vs 裁剪版对比**（第一组关键实验）：

| 参数 | 缩放版 | 裁剪版 |
|---|---|---|
| 图像尺寸 | 1333×800 | 1024×1024 |
| 学习率 | 0.0025 | 0.005 |
| 训练数据 | 404张大图 | 2955个patch |
| 验证数据 | 102张大图 | 766个patch |

| 指标 | 缩放版（E12） | 裁剪版（E4） | 裁剪版（E16） |
|---|:---:|:---:|:---:|
| bbox_mAP | 2.4% | 4.8% | **6.8%** |
| segm_mAP | 2.5% | 5.0% | **7.1%** |

**裁剪版全面优于缩放版**——缩放把大图压到 1333×800，微小缺陷直接被抹掉；裁剪保留原始分辨率，缺陷信号完整。

### 2.2 Mask R-CNN 的五个问题

基线 mAP 6.8% 看起来很低，拆开分析发现是多个结构性问题的叠加：

| 问题 | 表现 | 影响 |
|---|---|---|
| 收敛速度远低于预期 | E4→E16（12个epoch），mAP 仅从 4.8% 提升到 6.8% | 原预估 15-30% 过于乐观 |
| 小目标检测几乎完全失败 | bbox_mAP_s（area<32²）仅 0.6% | FPN 对 <32² 缺陷召回严重不足 |
| 类别不均衡极端严重 | CD/D/G 完全未检出（0 或 nan） | 罕见类样本极少 |
| 数据增强域不一致 | 不同方法/参数增强后的图像混合训练 | 模型浪费容量学习"适应增强风格" |
| RPN 已收敛但检测头未跟上 | RPN loss 极低（~0.01），但 cls/bbox/mask loss 仍高 | 缺陷特征未被有效编码到 ROI 特征 |

### 2.3 为什么放弃 Mask R-CNN 转向 YOLO-Seg

| 原因 | 具体表现 |
|---|---|
| 工程重 | mmcv/mmdet 环境依赖复杂，一次环境崩溃损失 1-2 天 |
| 训练慢 | 滑窗切片后 patch 数激增，单次实验 ~6-8 小时 |
| 小样本效果有限 | 500 张原图下 RoI 头过拟合，B 类召回始终 <0.20 |

转向 YOLO26-Seg（~26M 参数）——轻量、工程化好、便于快速消融。早期也尝试了 RF-DETR，最终以 YOLO26-Seg + SDE + DAF 方案更稳定准确。

### 2.4 统一实验配置

| 项 | 配置 |
|---|---|
| 输入分辨率 | 1024×1024（AHTF 切片输出） |
| Backbone | YOLO26（~26M 参数，C3k2/C2PSA 结构） |
| 优化器 | SGD（lr=0.01，momentum=0.937，weight_decay=0.0005） |
| 训练 | 100 Epoch，batch=12，imgsz=1024 |
| 数据增强 | 默认 YOLO 增强（mosaic/mixup/flip/etc.） |
| 硬件 | NVIDIA A100 80GB，Ultralytics YOLO 框架 |
| 数据 | 训练 6034 张 patch / 验证 3721 张 patch / 验证实例 4674 个 |

### 2.5 E1 baseline 缺失说明

E1（YOLO26-Seg + AHTF v2.1-R 纯 baseline，无 SDE/DAF/Boundary）当前未在服务器找到 best.pt/results.csv。历史文档曾记录约 0.15 的 Mask mAP50-95，但无权重可复测，不作为正式对比纳入主表。如需严格 baseline，后续应重新训练 E1 并归档。

## 三、方法：三条线索推进

### 线索 A：数据策略——AHTF v2.1-R（贡献最大）

**动机**：大图直接训练丢失小缺陷；固定滑窗切片导致缺陷被边界截断。AHTF（Adaptive High-overlap Tile Fusion）的设计目的是尽量保证每个缺陷至少完整出现在一个 patch 中。

**核心机制**：

| 设计点 | 作用 |
|---|---|
| 自适应切片 | 根据图像尺寸和缺陷分布生成 patch，非固定网格 |
| 高重叠策略 | 增加缺陷完整落入某个 patch 的概率 |
| valid_ratio | 评估实例在 patch 内保留比例，过滤截断严重的样本 |
| visible_short_resized | 评估 resize 后短边是否仍可见，过滤训练价值过低样本 |
| normal / weak / drop | 按样本质量区分，保留 normal，限制 weak，丢弃 drop |
| rescue window | 为被截断或弱小实例补充更完整训练视野 |
| 背景 patch | 保留无缺陷正常区域，帮助模型学习正常背景，降低误检 |

数据规模：约 6034 张训练 patch / 3721 张验证 patch / 4674 个验证实例。

> **教训 #2**：AHTF 是本项目贡献最大的单一改进——它直接决定了小缺陷"能不能被模型看到"。如果先换模型而不修数据策略，E2-E5 的收益会大打折扣。

### 线索 B：类别合并（降低长尾难度）

**动机**：第一批数据仅约 500 张，10类中 CD/D/G 完全未检出，CA/CC 极低。部分类别在 X 射线下表现极其接近（收缩四子类 Ca/Cb/Cc/Cd），标注本身就存在混淆。

**合并策略**：

| 原始类别 | 合并后 | 合并理由 |
|---|---|---|
| A 气孔 | **A**（保持独立） | 形态特征明显，可区分 |
| B 砂眼夹渣 | **B**（保持独立） | 形态特征明显，可区分 |
| Ca/Cb/Cc/Cd 四类收缩 + D裂纹 + E热断裂 + F镶件 + G斑点 | **C**（合并） | 第一批数据量小，子类样本极少，标注人员都难以区分 |

合并后从 10 类降到 **3 类**（A/B/C），大幅降低分类难度。

> **教训 #3**：在标注质量/类别定义不完善的工业场景，**合并易混淆类别比硬训10类更有效**。第一批数据量小，子类样本不足以独立学习。后续数据量增加后再细分。

### 线索 C：模型增强——SDE + DAF（E3 当前最优）

**动机**：AHTF 解决了"缺陷可见性"，但 B 类弱小缺陷的特征仍然太弱，YOLO26 的 P3/P4/P5 多尺度融合在极弱信号下不够用。

**SDE（Small-Defect Enhancement，小弱缺陷增强）**：在 YOLO26 Neck 的 C3k2 模块中二次增强，对 P3/P4/P5 特征做局部纹理和边缘响应增强，提升 B 类召回。

**DAF（Defect-Aware Fusion，缺陷感知尺度增强）**：让 P3 用 C3k2（细节保留），P4/P5 用 C2PSA（上下文建模），让不同尺度分别关注细节、结构和上下文，避免单一尺度处理所有缺陷。

## 四、消融实验：E2-E5 统一复测结果

> 以下所有指标均用各自 weights/best.pt 在同一验证集上重新运行 `yolo segment val` 得到。E1 baseline 未核验，不纳入主表。

### 4.1 整体对比

| 实验 | 方法组合 | all Mask mAP50 | all Mask mAP50-95 | B类 Mask Recall | B类 Mask mAP50 | 结论 |
|---|---|:---:|:---:|:---:|:---:|---|
| E2 | +SDE | 0.386 | 0.161 | 0.238 | 0.216 | B类有小幅改善，但整体略低于E3 |
| **E3** | **+SDE+DAF** | **0.400** | **0.165** | **0.288** | **0.239** | **当前综合最优，推荐为主模型** |
| E4 | +SDE+Boundary Loss | 0.388 | 0.164 | 0.223 | 0.228 | 边界略有帮助，但B类召回下降 |
| E5 | +SDE+DAF+Boundary Loss | 0.385 | 0.162 | 0.233 | 0.211 | 低于E3，Boundary无增益 |

### 4.2 三个关键发现

**发现1：数据策略 > 模型增强**。AHTF 切片是本项目贡献最大的单一改进。E2/E3 的 SDE/DAF 是在此基础上的增量优化，总收益约 +0.01 mAP50-95，远小于从"无切片"到"AHTF"的跨越。

**发现2：SDE+DAF 组合有效（E3），B类 Recall +21%**。E2（仅 SDE）到 E3（+DAF），B类 Mask Recall 从 0.238→0.288（+21%），all Mask mAP50 从 0.386→0.400（+3.6%）。DAF 的尺度感知增强对多尺度缺陷表达的改善比单纯 SDE 更明显。

**发现3：简单 Boundary Loss 不适合当前任务**。E4/E5 均未超过 E3，尤其 E5 叠加后 B/C 类表现反而下降。低对比度边界上的梯度信号本身就很弱，加边界权重等于在弱信号上放大噪声。

> **教训 #4**：在低对比度缺陷边界上，简单 loss 改动难以改善 mask 精细度。需要的是高分辨率引导（P2 detail branch）或显式 Boundary Branch，而非在已模糊的特征图上加权重。

## 五、失败实验分析

### 5.1 Mask R-CNN / MMDetection

| 策略 | 结果 | 原因分析 |
|---|---|---|
| Mask R-CNN 缩放版 | mAP 2.4% | 缩放抹掉微小缺陷 |
| Mask R-CNN 裁剪版 | mAP 6.8%，B类召回<0.15 | 工程重、小样本下RoI头过拟合、迭代效率低 |

### 5.2 Boundary-aware Loss（E4/E5）

| 策略 | 结果 | 原因分析 |
|---|---|---|
| E4（SDE+Boundary） | 未超E3，B类召回下降 | 低对比度边界梯度信号弱 |
| E5（SDE+DAF+Boundary） | 低于E3，B/C类均下降 | 叠加后放大噪声 |

**为什么简单 Boundary Loss 会失败**：X射线低对比度缺陷边界上，GT mask 边界本身就有标注者间差异（约 2-5 像素的模糊带）。加边界权重等于让模型去拟合一个本就不精确的边界——模型最终选择忽略这个弱约束。

**核心判断**：低对比度工业图像中，边界标注本身存在不确定性。此时需要的是更丰富的边界特征（高分辨率引导、显式边界分支），而非在损失上加权重。

## 六、整体定性：从缺陷检测到工件等级

这是整个项目最独特的部分——检测模型只告诉你"图上有哪些缺陷"，但业务需要的是"这个工件合格不合格"。

### 6.1 定性规则的设计

**输入**：一张底片上检出的所有缺陷（类型 + 位置 + mask + 面积 + 置信度）
**输出**：工件整体定性类别 + 严重等级（1-5级）

**工件定性类别**：
- 气孔主导型（A类缺陷为主）
- 裂纹主导型（D/E类缺陷为主）
- 复合缺陷型（多类缺陷混合）

**规则逻辑**：基于缺陷类型分布 + 数量阈值 + 最大尺寸阈值的规则引擎。阶段一输出结构化数据（缺陷字段），交由阶段二处理。阶段二可由大模型评片或专家规则完成。

### 6.2 全流程闭环

```
底片输入 → 图像增强 → AHTF切片 → YOLO26-Seg检测 → 缺陷汇总 → 定性规则 → 工件等级+描述
    ↑                                                                        ↓
    └───────────────────── 全流程无人工介入 ─────────────────────────────────┘
```

> **教训 #5**：在基线 mAP 仅 6.8% 的低起点下，我学到一个重要的工程判断——**与其等到检测做到 90% 再启动定性，不如用 A/B 等高检出类先跑通全流程**。阶段二的定性规则设计不依赖检测精度到多高，它依赖的是"缺陷分布→等级"的映射逻辑。尽早打通全流程，可以提前暴露系统集成问题。

## 七、部署闭环：从 patch 到原图

### 7.1 大图推理与回贴融合

| 步骤 | 处理内容 | 注意事项 |
|---|---|---|
| 大图切片 | 按 AHTF v2.1-R 兼容的窗口策略切片 | 推理切片参数需与训练一致 |
| patch 推理 | 对每个 patch 运行 E3 模型 | 保存 patch_id、窗口坐标、置信度 |
| 坐标回贴 | 局部坐标转换回原图坐标 | mask 点和 bbox 同时转换 |
| 重叠融合 | 重叠区域 NMS 或 mask 合并 | 同一缺陷跨 patch 不应重复计数 |
| 实例过滤 | 按置信度、面积过滤异常预测 | 小缺陷不能因面积阈值过高被误删 |
| 结果导出 | 导出原图级 JSON/CSV + 可视化 | 供 Qt 和阶段二读取 |

### 7.2 Qt 软件原型

已完成可运行原型，支持图像导入、排序、显示、缩放平移、结果查看、人工修改、确认通过和基础导出。

### 7.3 推理性能

E3 模型（YOLO26-Seg，~26M 参数）在 A100 上：

| 模式 | 单 patch 推理耗时 | 吞吐（估算） |
|---|---|---|
| FP32 | ~15 ms | ~67 img/s |
| FP16 | ~10 ms | ~100 img/s |

FP16 推理精度无损，可部署至产线 GPU。

## 九、和 CXMT 经验的对比

| 维度 | CXMT（晶圆缺陷分类） | 讯飞（X射线评片） |
|---|---|---|
| 任务类型 | 图像分类 | 目标检测 + 实例分割 + 规则定性 |
| 图像规模 | 224×224 小图 | >2000×2000 超大图 |
| 难点 | 极端长尾 + 低对比度 | 超大图 + 小样本 + 弱小缺陷 + 全流程闭环 |
| 数据策略 | 8:2分层随机划分 | AHTF 自适应高重叠切片（贡献最大） |
| 类别策略 | 保持5类，用 LDAM margin 扩边界 | 10类合并为3类，降低标注混淆 |
| 核心方法 | LDAM + 预训练迁移 + 蒸馏 | AHTF切片 + SDE/DAF + 类别合并 |
| 失败实验 | DRW/SupCon/MIM/CLAHE/TTA（8项） | Boundary Loss + Mask R-CNN（2项） |
| 落地形式 | 分类模型部署 | 全流程系统闭环 + Qt软件 |
| 方法学 | 温和引导而非暴力施压 | **数据策略 > 模型增强 > 损失函数** |

两个项目的方法学截然不同但互补：CXMT 是"把一个单点任务做到极致"，讯飞是"把一个全流程系统跑通"。

## 十、可复现性

> 因公司 NDA，原始数据与客户工艺细节不可公开。本文方法在公开工业缺陷数据集（如 NEU-DET、PCB Defect）上可复现核心结论——大图切片策略 + 小目标检测模块的组合增益。

复现关键点：

- 骨干：ultralytics 库加载 YOLO26-Seg

## 十一、面试预演 Q&A

**Q1：为什么从 Mask R-CNN 转向 YOLO-Seg？**
A：Mask R-CNN 是合理的早期基线，验证了数据转换和实例分割链路可行。但问题在三个层面：①工程重，mmcv/mmdet 环境复杂，消融效率低；②训练慢，单次实验 6-8 小时；③小样本下 RoI 头过拟合，B类召回始终 <0.15。YOLO-Seg 轻量（~26M）、工程化好、便于快速消融。早期也尝试了 RF-DETR，最终以 YOLO26-Seg + SDE + DAF 更稳定。

**Q2：AHTF 和普通滑窗切片有什么区别？**
A：普通滑窗是固定网格，缺陷可能被切在边界上。AHTF 的核心是自适应高重叠——根据图像尺寸和缺陷分布生成 patch，用 valid_ratio 评估实例保留比例，用 rescue window 为被截断实例补充完整视野。它的目标不是增加 patch 数量，而是保证每个缺陷至少完整出现在一个训练 patch 中。

**Q3：E3 的 all Mask mAP50-95 只有 0.165，这算好吗？**
A：不高，但这是当前数据条件下的真实水平。Mask mAP50-95 要求 IoU 从 0.5 到 0.95 取平均，在 X射线低对比度边界上本身就很难达到高 IoU。我更关注的是 B类 Recall +21%——这直接改善了最困难类别的检出能力，对实际评片系统的意义大于整体 mAP 的微小提升。

**Q4：Boundary Loss 在 E4/E5 失败了，你学到了什么？**
A：低对比度边界上不能简单用 loss 加权重。X射线缺陷的 GT mask 边界本身有标注者间差异（约 2-5 像素模糊带），加边界权重等于让模型拟合一个不精确的边界。后续应使用 P2 高分辨率特征引导的 detail branch 或显式 Boundary Branch，让模型在特征层面获得更多边界信息。

**Q5：10类合并为3类会不会丢失信息？业务方接受吗？**
A：会丢失子类信息，但合并的类（收缩四子类 Ca/Cb/Cc/Cd + 裂纹D + 热断裂E + 镶件F + 斑点G）在 X射线下本身就难以区分，标注人员的一致率都很低。第一批数据仅 500 张，子类样本不足以独立学习。合并为 3 类是"先在粗粒度上建立可用基线"的工程妥协。后续数据量增加后再细分。

**Q6：大图回贴融合的难点在哪？**
A：三个难点：①坐标转换——patch 级 mask 的点和 bbox 要同时转回原图坐标；②跨 patch 实例合并——一个缺陷可能出现在多个相邻 patch 中，需要 NMS 或 mask 合并去重；③边界预测不一致——同一缺陷在两个 patch 中的预测 mask 可能略有差异，合并时需做加权平均或投票。

**Q7：阶段一和阶段二怎么衔接？**
A：阶段一输出每个缺陷的结构化信息（类别、bbox、mask、面积、置信度），阶段二根据这些信息判断工件整体定性、严重等级和专业描述。关键是要尽早确定两阶段之间的 JSON schema。如果接口字段不一致，后面联调会花大量时间改格式。

**Q8：这个系统和 CXMT 的缺陷分类有什么方法论上的关联和区别？**
A：关联：都是工业缺陷、都面临小样本和类别不均衡。区别：CXMT 是纯分类任务，224×224 小图，瓶颈在损失函数和预训练，方法学是"温和引导"；讯飞是检测+定性任务，>2000×2000 超大图，瓶颈在小目标召回和全流程闭环，方法学是"数据策略 > 模型增强 > 损失函数"。CXMT 教我"把单点做到极致"，讯飞教我"把全流程跑通"。
