# 制鞋机器人视觉系统：从实例分割到三维涂胶轨迹的全链路落地

> 作者：李国杰 | 福建省科技重大专项（2024.9 - 2026.3）
> 系列：CV 算法工程笔记 · 第 03 篇
> 相关产出：2项发明专利（第一/第二发明人）+ 1篇论文（第一作者，在审）

## TL;DR

- **任务**：面向制鞋产线自动化涂胶需求，实现个性化鞋型鞋底/鞋面的自动识别与涂胶轨迹导引。从RGB-D图像输入到带位姿信息的涂胶轨迹输出，全链路自动化。
- **挑战**：鞋底与背景颜色/纹理接近（伪装分割问题）、个性化鞋型种类多、点云轮廓提取需连续平滑、产线实时性要求。
- **做法**：三阶段递进——实例分割（轻量模型+RGB-D伪装分割）→ 三维重建与点云处理（单视图重建+多平面投影+几何特征融合）→ 轨迹提取与工程落地（几何分析+工艺参数+模型轻量化）。
- **结果**：识别准确率 >99%，涂胶轨迹定位精度 ≤1mm，2项发明专利授权，独立打通"数据采集→算法研发→产线部署验证"全流程。
- **方法学沉淀**：**感知→重建→轨迹是递进关系，每一步的上游质量决定下游上限**——分割不准，点云再好也提取不出正确轮廓；点云不连续，轨迹算法再优也生成不了平滑路径。

## 一、问题定义：为什么"自动涂胶"不是简单的边缘检测

### 1.1 任务背景

制鞋产线的涂胶工序长期依赖人工——工人手持胶枪沿鞋底边缘涂胶，效率低、质量不稳定、且胶水挥发对工人健康有害。自动化涂胶的核心难点是：每只鞋底的形状、尺码、材质都不同，固定轨迹的机器人无法适应"个性化鞋型"。

这个项目的目标：**输入鞋底的RGB-D图像 → 自动识别涂胶区域 → 重建三维轮廓 → 生成带位姿信息的涂胶轨迹 → 导引机器人执行**。

### 1.2 为什么这不是简单的边缘检测

| 难点 | 具体表现 | 为什么难 |
|---|---|---|
| 伪装分割 | 鞋底与背景颜色/纹理接近，RGB图像中边界模糊 | 纯RGB分割容易漏检/误检，需要深度信息辅助 |
| 个性化鞋型 | 每款鞋的涂胶区域形状不同，无法预定义模板 | 模型必须泛化到未见过的鞋型 |
| 三维轮廓连续性 | 涂胶轨迹必须连续、闭合、平滑，不能有断点 | 点云噪声/缺失会导致轮廓断裂，直接影响涂胶质量 |
| 位姿信息 | 机器人不仅需要轨迹点的位置(x,y,z)，还需要法向量(姿态) | 涂胶枪需要垂直于鞋底曲面，姿态错误会导致涂胶不均 |
| 实时性 | 产线节拍要求快速推理 | 模型需轻量化，从图像到轨迹全流程需在产线可接受时间内完成 |
| 精度要求 | 涂胶轨迹定位精度 ≤1mm | 亚毫米级精度对视觉感知和点云处理都提出极高要求 |

> **教训 #1**：这个任务的难度不在于任何一个单点环节，而在于**全链路的误差累积**——分割差1像素，点云就偏一点，轨迹就偏一截，涂胶就不到位。每一步都必须做到足够精确，否则误差会级联放大。

### 1.3 三阶段架构设计

```
阶段一：实例分割（感知）
  RGB-D鞋底图像 → 轻量分割模型 → 鞋底涂胶区域像素级mask

阶段二：三维重建与点云处理（重建）
  分割mask + 深度信息 → 涂胶区域点云 → 多平面投影 + 几何特征融合 → 连续平滑的三维轮廓

阶段三：轨迹提取与工程落地（轨迹）
  三维轮廓 → 几何分析 + 工艺参数 → 带位姿的涂胶轨迹 → 模型轻量化 → 产线部署
```

三阶段递进，每一步以上一步的输出为输入。和讯飞的"两阶段评片"不同，这里的三阶段是**技术链路**的递进（感知→重建→轨迹），不是任务分解。

## 二、阶段一：实例分割——RGB-D伪装分割

### 2.1 为什么鞋底分割是"伪装"问题

鞋底放在工作台上采集图像时，鞋底颜色与工作台背景颜色可能接近，在RGB图像中边界模糊——这在计算机视觉中属于**伪装目标分割（Camouflaged Object Segmentation）**问题。

纯RGB分割在这种场景下容易失败：鞋底和背景的纹理、颜色相似，CNN难以提取有效的判别特征。解决方案是**引入深度信息**——鞋底和工作台在Z轴上有高度差，深度图中边界清晰。

### 2.2 RGB-D双模态分割方案

**专利2的核心思路**（第二发明人）：基于RGB-D的伪装实例分割，利用深度信息辅助RGB分割，生成涂胶区域的点云。

| 模态 | 作用 | 优势 |
|---|---|---|
| RGB图像 | 提取纹理/颜色特征 | 鞋底表面纹路、品牌标识 |
| 深度图像 | 提供Z轴高度差信息 | 鞋底与背景的深度边界清晰 |
| 融合 | RGB特征 + 深度特征联合编码 | 互补：RGB管"是什么"，深度管"在哪" |

### 2.3 轻量分割模型设计

面向产线部署的实时性要求，分割模型需要轻量。结合论文《基于动态路由与拓扑聚合的实例分割网络》（第一作者，在审）的研究：

**动态路由**：根据输入鞋型的尺度分布，动态选择特征传播路径。不同鞋型（运动鞋/皮鞋/靴子）的涂胶区域形状和尺度差异大，静态网络结构难以兼顾——动态路由让网络自适应不同鞋型。

**拓扑聚合**：利用鞋底轮廓的拓扑结构信息（闭合性、连通性）增强特征聚合。鞋底涂胶区域是一个连续闭合的环状结构，拓扑约束能帮助模型生成更完整的分割mask。

### 2.4 分割结果

- 识别准确率 >99%（产线验收级别，像素级mIoU等论文实验数据因论文在审暂不公开）
- 模型经轻量化设计，满足产线实时性要求
- 详见论文《基于动态路由与拓扑聚合的实例分割网络》（第一作者，在审）

> **教训 #2**：在工业场景中，"伪装分割"不是学术上的benchmark竞赛，而是"深度信息能不能补上RGB的短板"的工程问题。RGB-D融合的价值不在于精度提升多少个百分点，而在于**在背景干扰场景下稳定可用**——纯RGB在实验室可能99%，但产线上换个颜色的桌子就降到80%。RGB-D让模型对背景变化鲁棒。

## 三、阶段二：三维重建与点云处理

### 3.1 从分割mask到点云

分割得到涂胶区域的像素级mask后，结合深度相机的内参矩阵，将mask区域的像素反投影到三维空间，生成涂胶区域的点云。

### 3.2 单视图三维重建

**专利1的核心创新**（第一发明人）：设计协同编码架构构建单视图三维重建网络。

传统方法需要多视角图像做三维重建，但产线上只有一台固定相机（单视图）。单视图重建的核心挑战是**深度歧义**——从单张图像无法直接恢复完整的三维结构。

协同编码架构的思路：
- **可见光分支**：提取鞋底的纹理/几何特征
- **激光/深度分支**：提取鞋底的三维形貌特征
- **协同编码**：两个分支在编码阶段交互融合，而非简单后期拼接

### 3.3 特征融合标定：视觉与激光数据的空间配准

专利1中的**特征融合标定模块**：

| 步骤 | 做什么 | 技术细节 |
|---|---|---|
| 虚拟标定靶点 | 基于鞋底几何结构生成标定靶点 | 不需要物理标定板，用鞋底自身的几何特征 |
| 空间配准 | 可见光图像与三维点云对齐 | 利用包含几何结构信息的可见光图像与点云实现配准 |
| 深度学习标定 | 迭代更新标定参数 | 通过深度学习模型输出配准变换矩阵 |

> 这个设计的巧妙之处在于**不需要额外的标定设备**——用鞋底自身的几何结构作为标定参照，简化了产线部署流程。

### 3.4 多平面投影与几何特征融合

从鞋底点云中提取涂胶轮廓的核心方法：**多平面投影 + 几何特征融合**。

```
鞋底点云
    ↓
多平面投影：从不同方向对点云做切面，获取截面轮廓
    ↓
几何特征提取：每个截面的最高点/边缘点/曲率变化点
    ↓
特征融合：融合多个投影方向的几何特征
    ↓
轮廓拟合：拟合连续、平滑、闭合的三维涂胶轮廓
```

**为什么用多平面投影而非单方向扫描**：鞋底是复杂曲面，单方向扫描可能在某些曲率变化剧烈的区域丢失轮廓点。多平面投影从多个方向获取截面，融合后能覆盖鞋底的完整轮廓。

### 3.5 智能误差校正

专利1中的**智能误差校正模块**：基于涂胶轮廓与设计轨迹的几何偏差，利用生成对抗网络（GAN）在曲率连续性与涂胶工艺间隙的预设约束下生成修正轮廓。

| 校正维度 | 约束条件 | 目标 |
|---|---|---|
| 曲率连续性 | 轮廓曲率不能突变 | 保证涂胶轨迹平滑，机器人运动无抖动 |
| 涂胶工艺间隙 | 相邻轨迹点间距符合工艺要求 | 保证涂胶均匀，无漏涂/堆胶 |

> **教训 #3**：点云轮廓提取的最大敌人是**噪声和缺失**。工业现场的深度相机受光照、反射、材质影响，点云常有噪点和空洞。多平面投影的冗余性（多方向采样）和GAN的修正能力（在约束下补全）是应对这两个问题的组合拳。

## 四、阶段三：轨迹提取与工程落地

### 4.1 从轮廓到轨迹

三维涂胶轮廓是"线"，涂胶轨迹是"带位姿的点序列"——机器人需要每个轨迹点的(x,y,z)位置和法向量(姿态)。

**轨迹提取算法**：

| 步骤 | 做什么 | 输出 |
|---|---|---|
| 轮廓离散化 | 将连续轮廓按曲率自适应离散为点序列 | 曲率大处密、曲率小处疏 |
| 法向量计算 | 对每个点估计局部曲面法向量 | 涂胶枪姿态 |
| 工艺参数注入 | 结合涂胶宽度、间距、速度等工艺要求 | 最终轨迹点序列 |
| 坐标变换 | 从相机坐标系变换到机器人坐标系 | 机器人可执行的运动指令 |

### 4.2 模型轻量化与推理加速

面向产线实时性要求，对分割模型做轻量化：

| 优化 | 方法 | 效果 |
|---|---|---|
| 模型压缩 | 轻量 backbone + 动态路由减少冗余计算 | 满足产线部署资源约束 |
| 推理加速 | 全链路优化（分割+点云+轨迹） | 满足产线实时性 |
| 全链路优化 | 分割+点云+轨迹全流程耗时优化 | **产线节拍 3s/只** |

### 4.3 产线部署验证

独立打通"数据采集→算法研发→产线部署验证"全流程：

```
数据采集：RGB-D相机采集鞋底图像（多鞋型/多尺码/多材质）
    ↓
算法研发：分割→点云→轨迹（离线开发+验证）
    ↓
产线部署：模型部署到产线工控机 + 机器人执行涂胶
    ↓
验证：涂胶轨迹定位精度 ≤1mm，识别准确率 >99%
```

> **教训 #4**：产线部署和实验室验证是两回事。实验室里点云干净、光照可控、鞋底摆放标准；产线上光照变化、鞋底随意摆放、点云有噪声。模型在实验室到产线的精度衰减是必须面对的问题——这也是为什么RGB-D融合和GAN误差校正不是"锦上添花"而是"必需品"。

## 九、面试预演 Q&A

**Q1：为什么用RGB-D而不是纯RGB或纯3D？**
A：纯RGB在鞋底与背景颜色接近时会失败——这是伪装分割问题。纯3D（只用深度）能解决边界问题，但丢失了鞋底表面的纹理信息，无法区分涂胶区域和非涂胶区域（两者在高度上可能没差异）。RGB-D融合让深度管"边界在哪"，RGB管"哪块是涂胶区域"，互补解决。

**Q2：单视图三维重建怎么做？不需要多视角吗？**
A：传统三维重建确实需要多视角，但产线上只有一台固定相机。专利1的解法是协同编码——可见光和激光/深度两个分支在编码阶段就交互融合，让网络从单视图中"推断"出完整的三维结构。这不如多视角重建精确，但配合后面的多平面投影和GAN误差校正，精度足以满足≤1mm的要求。

**Q3：涂胶轨迹为什么需要位姿（法向量）？只用(x,y,z)不行吗？**
A：涂胶枪需要垂直于鞋底曲面才能保证涂胶均匀。如果只有位置没有姿态，涂胶枪的角度是固定的——在平面上没问题，但鞋底是复杂曲面，曲面倾斜处涂胶枪不垂直会导致涂胶偏移/不均。法向量告诉机器人每个轨迹点该怎么调整涂胶枪角度。

**Q4：≤1mm的精度怎么保证？**
A：三个环节共同保证：①分割精度——RGB-D融合+动态路由保证mask准确；②点云精度——多平面投影的冗余采样+GAN误差校正抑制噪声；③轨迹精度——曲率自适应离散+法向量精确估计。每个环节的误差都被控制在亚毫米级，级联后总精度≤1mm。

**Q5：动态路由和拓扑聚合分别解决什么问题？**
A：动态路由解决"不同鞋型尺度差异大"的问题——运动鞋和皮鞋的涂胶区域形状/尺度差异大，静态网络结构难以兼顾，动态路由根据输入自适应选择路径。拓扑聚合解决"分割mask不闭合"的问题——鞋底涂胶区域是一个闭合环，但CNN可能输出有断点的mask，拓扑约束利用闭合性先验帮助生成完整轮廓。

**Q6：这个项目和你工业缺陷项目有什么关联？**
A：关联在"全链路精度"——CXMT是单点分类，讯飞是检测+定性的两阶段，本项目是分割+3D+轨迹的三阶段。三个项目的复杂度递增，但核心方法学一致：每一步的上游质量决定下游上限。本项目最深刻的是"误差级联放大"——分割差1像素，点云偏一点，轨迹偏一截，涂胶就不到位。这让我在后来的CXMT项目中特别重视"上游瓶颈优先"。

**Q7：GAN误差校正为什么用GAN不用其他方法？**
A：GAN的优势是"在约束下生成"而非"在约束下优化"。传统优化方法（如最小二乘拟合）在点云缺失严重时可能过拟合或失败，GAN能从学习到的轮廓分布中"补全"缺失部分，同时通过判别器保证生成轮廓的合理性。曲率连续性和涂胶工艺间隙作为约束条件嵌入生成器，保证修正后的轮廓既平滑又符合工艺要求。

**Q8：产线部署遇到的最大问题是什么？**
A：实验室到产线的精度衰减。实验室里点云干净、光照可控，产线上光照变化导致RGB分割波动、鞋底材质反射导致点云噪声。我的应对是：①RGB-D融合让模型对光照变化鲁棒；②多平面投影的冗余采样抑制点云噪声；③GAN误差校正兜底。这些不是"锦上添花"，而是产线可用的"必需品"。
